# حافظه‌ی پایدار روایت

این نسخه علاوه بر خلاصه‌ی متنی، یک `storyBible` ساختاریافته ذخیره می‌کند:

- `clues`: سرنخ‌ها با شناسه‌ی ثابت، وضعیت و حقیقت ثبت‌شده
- `decisions`: تصمیم‌های مهم بازیکن و پیامد قطعی آن‌ها
- `secrets`: رازهای آشکارشده یا هنوز پنهان
- `flags`: پرچم‌های شاخه‌های داستان
- `currentArc`: شاخه یا مرحله‌ی فعال داستان

هر نوبت فقط موارد اخیر و مرتبط به مدل داده می‌شود، اما داده‌ی ساختاریافته در فایل جلسه یا MongoDB باقی می‌ماند. مدل اجازه ندارد این موارد را حذف کند و سرور موارد دارای شناسه را به‌روزرسانی می‌کند.

برای اجرای بررسی syntax:

```bash
npm test
```

## هماهنگی کوئست اصلی با داستان (دروازه‌ی سرنخ)

پیشروی خط اصلی دیگر به AI یا کلمات کلیدی آزاد وابسته نیست. سرور هر نوبت تصمیم می‌گیرد:

- هر مرحله در `memory/world.js` (آرایه‌ی `STAGE_CLUES`) مکان مجاز، حداقل نوبت تحقیق (`minTurns`)، نیمه‌سرنخ (`hint`) و حقیقت ثابت (`truth`) دارد.
- سرنخ فقط وقتی «قابل آشکار شدن» است که بازیکن در مکان درست باشد، پیامش واقعاً تحقیق باشد (بررسی، گشتن، پرسیدن، خواندن...) و به حداقل نوبت رسیده باشد.
- وضعیت هر نوبت به AI گفته می‌شود: «مجاز به آشکار کردن» / «فقط نیمه‌سرنخ» / «سرنخ اینجا نیست».
- AI نمی‌تواند سرنخ‌های `main_clue_*` را مستقیم ثبت کند؛ فقط سرور ثبتشان می‌کند.
- در هر نوبت حداکثر یک مرحله جلو می‌رود.

برای تنظیم سختی، `minTurns` یا متن `truth` هر مرحله را در `world.js` تغییر بده.
